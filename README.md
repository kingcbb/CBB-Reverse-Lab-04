## 📌 靶场说明
本靶场是授权校验类逆向练习样本，用于巩固本期课程所学：
- 静态分析：PE结构、字符串检索、导入表、反汇编阅读
- 动态调试：下断、寄存器跟踪、关键分支分析
- 授权逻辑逆向：序列号校验、条件判断、Flag提取、分支Patch等
- 推荐工具：x64dbg / x32dbg / IDA / Ghidra

🎯 任务目标：定位授权校验核心逻辑，分析判断流程，获取课程验证 Flag，完成课程作业提交。

## 📋 实验指引（本地主机）
1. 准备好调试工具，在本机 Windows 环境操作；
2. 将 `cbb逆向攻防课第4期_授权靶场.exe` 放置本地目录；
3. 优先静态分析，检索提示字符串，锁定可疑校验函数；
4. 使用调试器附加程序，跟踪授权判断代码分支；
5. 通过调试、逻辑还原、Patch等方式拿到验证Flag；
6. 按照授课老师要求提交Flag和分析笔记，完成靶场验证任务。
